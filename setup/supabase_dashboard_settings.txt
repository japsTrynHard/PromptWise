Supabase Dashboard configuration
================================

1. Authentication > Sign In / Providers > Email
   - Enable Email provider.
   - Enable Confirm email.

2. Authentication > URL Configuration
   - Site URL for local web: http://localhost:3000
   - Add redirect URL: http://localhost:3000
   - If development uses changing localhost paths, also allow: http://localhost:3000/**
   - Add mobile redirect URL: io.promptwise.app://auth-callback/
     This must match AppEnvironment and the Android/iOS URL handlers exactly.
   - Add the deployed Flutter web origin when available.

3. Authentication > Emails > SMTP Settings / Custom SMTP
   - Configure an external SMTP sender before ordinary Gmail OTP testing.
   - For Gmail development SMTP, follow AUTH_EMAIL_SETUP_GMAIL.md.

4. Authentication > Emails > Templates
   - Confirm sign up: setup/email_templates/confirm_signup.html
   - Magic Link / OTP: setup/email_templates/magic_link_otp.html
   - Password recovery is link-based. The default Supabase Reset Password
     email already supplies the required recovery link.
   - setup/email_templates/reset_password.html is a link-only template for use
     if template editing becomes available later; it is not required now.

5. Database migrations
   Do not rerun supabase/CURRENT_DB_ONE_RUN.sql on the existing linked project.
   From the repository root, inspect and then apply forward-only migrations:
   - npx supabase migration list
   - npx supabase db push --dry-run
   - npx supabase db push

   Deploy database-dependent Edge Functions only after their migration is live.

6. First administrator
   Register/create the user, then edit and run:
   setup/promote_first_admin.sql

7. Security
   Never place the service_role key, Supabase secret key, or SMTP password in Flutter.
   Flutter uses only the publishable key.
