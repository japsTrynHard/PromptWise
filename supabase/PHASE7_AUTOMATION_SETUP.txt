PromptWise Phase 7 - Content Automation Setup
==============================================

This Supabase folder is already prepared with:
- functions/promptwise-integrations/index.ts   (existing Phase 5 function)
- functions/content-automation/index.ts        (Phase 7 function)
- config.toml                                  (Phase 7 function config)
- your existing migrations/temp link data

From the Flutter project root, run:

1) Confirm the project is linked:
   npx supabase projects list

2) Confirm GROQ_API_KEY exists:
   npx supabase secrets list

   If GROQ_API_KEY is missing:
   npx supabase secrets set GROQ_API_KEY=YOUR_GROQ_KEY

3) Deploy the Phase 7 function:
   npx supabase functions deploy content-automation --use-api

4) Restart Flutter:
   flutter clean
   flutter pub get
   flutter analyze
   flutter run -d chrome

5) Test:
   Admin Web > Learning Studio > Check for updates now

6) Verify a run in Supabase SQL Editor:

   select
     trigger_mode,
     status,
     sources_checked,
     articles_discovered,
     drafts_created,
     error_message,
     started_at,
     completed_at
   from public.automation_runs
   order by started_at desc
   limit 10;

Expected after pressing Check for updates now:
- a new manual automation_runs row appears
- no "Edge Function is not deployed" error
- generated content, when available, stays Draft for admin review

Do not put GROQ_API_KEY inside Flutter lib/.
